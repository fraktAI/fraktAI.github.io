📋 Changelog

v1.6 03/2026 Nowość
  • Cache odpowiedzi API w localStorage — wyniki NIP, rachunków bankowych i NIP+konto są zapamiętywane i nie wymagają ponownego odpytania API
  • Cache wygasa automatycznie o północy — weryfikacje historyczne na konkretny dzień są przechowywane osobno
  • Błędy sieciowe nie są cachowane — ponowna próba zawsze trafia do API
  • Pasek stanu cache pod wynikami: liczba rekordów, zajętość i czas do wygaśnięcia
  • Przycisk ręcznego czyszczenia cache
v1.5 03/2026 Poprawka
  • Weryfikacja JPK przepisana na endpoint wsadowy /api/search/nips — wiele NIP-ów weryfikowanych w jednym zapytaniu zamiast osobnych requestów dla każdego
  • Znacząca redukcja liczby zapytań do API — mniejsze zużycie limitu przy dużych plikach JPK
  • Równoległe zapytania wsadowe — weryfikacja nawet dużych plików JPK przebiega w kilka sekund
  • Pasek postępu pokazuje liczbę przetworzonych NIP-ów i numer aktualnego zapytania
v1.4 03/2026 Poprawka
  • Naprawiono błąd weryfikacji na wskazany dzień — pola daty były blokowane przez atrybut max i wysyłały pustą wartość do API, które zwracało wyniki dla daty bieżącej
  • Domyślna data weryfikacji jest teraz zawsze ustawiana w dozwolonym zakresie
  • Dodano filtrowanie wyników po statusie — kliknięcie pillsów znaleziono / nie znaleziono / błędy zawęża listę
  • Wielowątkowość (5 równoległych requestów) dla wszystkich trybów weryfikacji
v1.3 03/2026 Poprawka
  • Przełącznik trybu ciemnego / jasnego z zapamiętywaniem preferencji
  • Dodano Changelog z historią wersji
  • Stopka z informacją o prawach autorskich © Dawid Frączek
v1.2 03/2026 Poprawka
  • Naprawiono parsowanie pliku JPK_V7M — poprawne odczytywanie tagów <NrDostawcy> i <NazwaDostawcy>
  • Zmiana metody weryfikacji JPK: zamiast NIP + rachunek → weryfikacja statusu VAT po samym NIP (/api/search/nip)
  • W wynikach JPK: wyświetlanie statusu VAT, nazwy z rejestru MF, REGON, adresu oraz rachunków z Białej Listy
  • Automatyczne ustawianie daty weryfikacji na ostatni dzień miesiąca z pliku JPK
v1.1 03/2026 Nowość
  • Dodano zakładkę JPK_VAT — import pliku XML i weryfikacja dostawców
  • W wynikach wyświetlana nazwa kontrahenta i NIP przy każdym rachunku
  • Eksport CSV rozszerzony o kolumny: status VAT, nazwa z rejestru MF, REGON
  • Poprawiono renderowanie wyników dla trybu NIP + konto: ID zapytania i data dla celów dokumentacyjnych
v1.0 03/2026 Nowość
  • Pierwsze wydanie aplikacji
  • Weryfikacja rachunków bankowych przez API MF (wl-api.mf.gov.pl)
  • Tryb: lista rachunków (do 30 naraz, automatyczne paginowanie dla większych zbiorów)
  • Tryb: weryfikacja NIP + numer rachunku
  • Import pliku Excel (.xlsx / .xls / .csv) z wyborem kolumny
  • Wyniki: szczegóły podmiotu (nazwa, NIP, REGON, status VAT, adres, rachunki)
  • Eksport wyników do CSV z kodowaniem UTF-8 BOM
