# Kalkulator zmiany formy współpracy – DEMO

Wersja demonstracyjna kalkulatora, który porównuje wynagrodzenie „na rękę” i koszt pracodawcy
**przed i po zmianie formy współpracy** (umowa o pracę, zlecenie, B2B).

**Demo online:** `[https://<twoj-login>.github.io/<nazwa-repozytorium>/](https://fraktai.github.io/kalkulator/index.html)`

## Co potrafi wersja demo
- umowa o pracę, umowa zlecenie, B2B (skala podatkowa lub podatek liniowy 19%),
- jedna współpraca „obecnie” i jedna „docelowo”, kwoty do 25 000 zł miesięcznie,
- zmiana „na rękę” i kosztu pracodawcy (miesięcznie),
- jasny i ciemny styl; działa w całości w przeglądarce, nic nie jest wysyłane ani zapisywane.

## Dostępne w pełnej wersji (nie jest częścią tego repozytorium)
wiele współprac jednej osoby, ryczałt, kontrakty menadżerskie i powołania, PPK, ulga dla młodych,
wyrównanie „na rękę”, zestawienia roczne i szczegółowe rozbicie składek i podatku,
porównanie wielu osób i spółek, import z Excela, wydruk, edycja stawek.
